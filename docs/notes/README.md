# Notes

Akin's own writing. One file per concept, named for the concept.

The rule from the learning contract: **if you can't explain it in ≤10 lines, you don't
understand it yet.** These files are the proof of work for the learning half of the
project. They're for you, not for anyone else — write badly, write fast, but write.

Suggested shape:

```markdown
# <concept>

## In one sentence

## What problem does it solve / what did people do before it

## The thing I got wrong first

## How I'd explain it to someone in an interview (30 seconds, out loud)
```

The third heading is the valuable one. Keep it honest.
